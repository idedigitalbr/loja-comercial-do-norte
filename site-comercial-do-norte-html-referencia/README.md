# Comercial do Norte

Site institucional oficial do **Comercial do Norte**, apresentando catálogo de ofertas, informações institucionais, departamentos e canais de atendimento direto.

---

## 🏢 Sobre o Projeto

O **Comercial do Norte** é o seu parceiro em economia, qualidade e conveniência para toda a sua família. Este projeto consiste em uma plataforma web de alta performance (Single Page Application institucional), desenvolvida com foco em velocidade, clareza e conversão.

---

## 🎨 Identidade Visual & Design System

- **Cor Primária (Azul Institucional):** `#264887`
- **Cor Secundária (Vermelho Ação):** `#E33C34`
- **Fundo da Interface:** `#F4F7FB`
- **Tipografia:** Lufga & Plus Jakarta Sans
- **Iconografia:** Lucide Icons (SVG nativo)

---

## 🛠️ Stack Tecnológica

- **Estrutura:** HTML5 Semântico
- **Estilização:** Tailwind CSS (CDN) + Folha de Estilos Canônica (`assets/css/design-system.css`)
- **Interatividade:** JavaScript Vanilla (ES6+)
- **Ícones:** Lucide Icons
- **Performance:** Imagens otimizadas e WebP

---

## 🚀 Execução Local

```bash
# Executar servidor local com Node.js
npx serve .
```

Abra no navegador em `http://localhost:3000` para navegar no site.
